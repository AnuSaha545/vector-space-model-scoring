# Vector Space Model Search Engine (TF-IDF)

## Overview
This project implements a simple **Information Retrieval System** using the **Vector Space Model (VSM)**. It ranks documents based on their relevance to a user query using **TF-IDF weighting** and **cosine similarity**.

---

## Features
- Reads multiple text documents from a folder
- Preprocesses text (lowercase, punctuation removal)
- Computes:
  - Term Frequency (TF)
  - Document Frequency (DF)
  - Inverse Document Frequency (IDF)
- Generates TF-IDF vectors
- Calculates cosine similarity between query and documents
- Ranks documents based on relevance
- Simple GUI using Tkinter

---

## Concepts Used
- Vector Space Model
- TF-IDF (Term Frequency – Inverse Document Frequency)
- Cosine Similarity
- Basic Natural Language Processing (NLP)
